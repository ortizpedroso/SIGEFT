DNS: subdomínio de inovesw.com.br apontando para a VPS
======================================================

Zona confirmada no hPanel: Meus domínios > inovesw.com.br > DNS / Servidores de nomes.
Aba correta: Registros DNS (não Subdomínios, não SSL).

www.inovesw.com.br     → plano Hostinger (ALIAS @ → *.cdn.hstgr.net). Não mexe.
sigep.inovesw.com.br   → registro A novo → IP público da VPS
www.eventosbr.app.br   → VPS, portas 80/443. Não mexe.

O que preencher no formulário "Gerenciar registros DNS"
-------------------------------------------------------
Tipo:         A          (no dropdown, NÃO use CNAME / SRV / TXT / CAA)
Nome:         sigep      (Hostinger completa para sigep.inovesw.com.br)
Aponta para:  IP da VPS  (o mesmo de www.eventosbr.app.br — NÃO use 191.96.63.250)
TTL:          300 ou o padrão (14400)

O IP 191.96.63.250 que já aparece no A de "ftp" é o plano compartilhado.
Se o subdomínio apontar para ele, a Métrica na VPS nunca recebe o tráfego.

O que NÃO fazer
---------------
- Aba Subdomínios / "Adicionar site": isso cria o hostname no plano compartilhado.
- CNAME para inovesw.com.br.cdn.hstgr.net: iria para a CDN do site, não para a VPS.
- Alterar ALIAS @, MX, TXT, SPF, DMARC: e-mail e o site principal quebram.

Conferir
--------
ping sigep.inovesw.com.br
O IP tem que ser o da VPS, não 191.96.63.250.

Depois, na VPS: vhost com server_name sigep.inovesw.com.br → 127.0.0.1:3001
e .env.production com CORS_ORIGINS / ALLOWED_HOSTS nesse hostname.
